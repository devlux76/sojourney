# Open licensing questions

Every shipped asset must allow commercial use and be credited in `CREDITS.md`. Anything not yet
confirmed is listed here until it is.

## Settled

- 2026-10-02: the ground's rock layer (`ground/rock_albedo.ktx2`, `rock_normal.ktx2`) is the "rockyGround"
  texture from the Babylon.js asset library (github.com/BabylonJS/Assets, `textures/`), which is CC BY 4.0
  ("unless specified otherwise in the asset folder"; `textures/` specifies nothing else). Credited in
  `CREDITS.md`. Project lead: assets of unrecorded origin are from the Babylon.js playground asset sets.

- 2026-10-02: the boat tour route (`public/packs/crater-lake/route/boat_tour.json`) is not a licensing
  issue. Project lead: "regardless of where we got the data from we're using public domain data."
  `CREDITS.md` still acknowledges OpenStreetMap.

- 2026-10-02: the NPS vegetation map and the NPS canopy-height grid behind
  `public/packs/crater-lake/ground/splatmap.png` are US Government works and so public domain
  (project lead, as an IP lawyer).
