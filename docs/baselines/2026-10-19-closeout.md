## Runtime defect found and repaired

The first headed Chrome run against merged main exposed a terrain fragment
compile error: `valueNoise : no matching overloaded function found` inside
`mappedSubstrateTintSoft`. The contact-smoothing helper called the GLSL function
before its declaration. TypeScript, the production build and the NullEngine tests
had all passed, demonstrating why the GPU check is required.

A forward declaration fixes GLSL compilation without changing the noise,
geology tint or WGSL implementation. The exact pre-fix file is preserved outside
the repository in the closeout archive.
